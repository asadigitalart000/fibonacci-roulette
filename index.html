House edge is 2.7% on single-zero and 5.26% on double-zero wheels. No staking system changes expected value.

How it works. After each spin, tap the number. A block qualifies when it missed both of the last 2 spins. If 2+ qualify, bet stake S on the two coldest (longest since last hit across the log; ties go to the lower block). Fewer than 2 = no bet. Ladder 1,1,2,3,5,8…: any block hit resets to 1; a loss (zeros included) steps up one rung; no-bet spins leave it alone. Win = +S net, loss = −2S.

Zero hedge (optional): Z covers 0 (35:1) or the 0/00 split (17:1). Assumption: the hedge is only placed on rounds where the dozen bet is live, so only those rounds count. Each live round without a zero is a hedge loss; after 23 in a row Z goes up 1 unit; any zero resets Z to 1 unit and the count to 0. A zero on a live round still steps the ladder up (both blocks lost).
